tools/generate_curated_defaults.py from an EXPLICIT catalog
(every biome is a written dict with a human note).

by_name templates → emergency BiomeRuleAutogen only.

classpath curated Biomes (seeded on sync) → toml migrate →

runtime autogen as curated truth.
