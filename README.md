# NewTerraForged

Unofficial continuation of TerraForged, maintained by **LiGaSt**. Not affiliated with the original TerraForged authors (dags, Won-Ton).

NewTerraForged is a Minecraft **1.19.2** world generation mod — a continuation of the TerraForged terrain engine with custom mega/giga caves, regional cave biomes, EGF overlays, and extended mod integration (Terralith, TerraBlender, Dynamic Trees, and others).

This branch is the **compile-ready product** for Minecraft 1.19.2 / Forge 43.x.

## Build

```powershell
.\gradlew.bat jar reobfJar -x test
```

Output: `build/libs/NewTerraForged-1.19.2-0.4.4-alpha-1.jar`
